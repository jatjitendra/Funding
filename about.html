About ApexFund

A demo built to show what a funded-trading platform looks like

ApexFund is a portfolio project inspired by real proprietary-trading-challenge platforms. It exists to demonstrate a full marketing experience for a funded-trading platform.

Every "account," "payout," and "profit split" you see here is a simulated number generated for demo purposes, not real money, brokerage accounts, or trading capital.

What this project demonstrates

  • A conversion-focused marketing site (hero, stats, pricing, FAQ)
  • A mock signup/login flow using localStorage
  • A mock checkout flow that creates a simulated account
  • A protected trader dashboard rendering that mock account
Our Approach

Built with plain HTML, CSS, and JavaScript

No frameworks, no backend, no build step — everything runs directly in the browser.

1

Static Pages

Every page is a plain HTML file styled with a shared stylesheet.

2

Mock Auth

Signup and login are simulated with the browser's localStorage.

3

Mock Checkout

Buying a "challenge" creates a simulated account record locally.

4

Dashboard

The dashboard reads and renders that simulated account data.

ApexFund is a portfolio/demo project. All trading, funding, and payouts shown are simulated for demonstration purposes only. This is not a real financial product or service.
